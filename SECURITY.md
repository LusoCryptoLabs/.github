# Security

Please do not report a security problem in a public issue, a pull request or a forum post.

## How to report

Use GitHub's private report on the repository: the Security tab, then "Report a vulnerability".
If that is not possible, write to hello@lusocryptolabs.com.

Include:

- what is affected: the repository, the version or commit, and the network (testnet, mainnet,
  a local chain);
- how to reproduce it;
- what someone could do with it.

A proof on testnet or on a local chain helps. Please do not test against funds that are not
yours.

## What happens next

We confirm that we received the report, work on the fix in private, and publish an advisory
with the fix. We credit you in it unless you prefer not.

A repository with its own SECURITY.md, for example one with deployed contracts, may add details
for that repository. Where they differ, that file applies.
